# Сервер «Вокал под бокал»

Вход через Telegram и хранение прогресса. Голос и видео сюда не попадают никогда: только id в Telegram и прогресс профилей (JSON).
Живёт на своём сервере Кита в РФ (Aeza, Ubuntu, 2 ГБ) на поддомене **api.законныевыходные.рф** (`api.xn--80aegcchwyadfe4gvdce.xn--p1ai`). На том же сервере работают бот и сайт «Законных выходных» - установка их не трогает.

## Как работает вход
1. Приложение: `POST /auth/start` -> одноразовая ссылка `t.me/<бот>?start=<код>` (живёт 10 минут).
2. Человек открывает бота и жмёт «Старт». Бот видит код и связывает его с id человека в Telegram.
3. Приложение спрашивает `GET /auth/poll?nonce=<код>` раз в 2 секунды и получает токен (один раз).
4. Дальше запросы с `Authorization: Bearer <токен>`. Токен живёт 180 дней с последнего использования.

## API
| Запрос | Что делает |
| --- | --- |
| `GET /health` | жив ли сервер |
| `POST /auth/start` | ссылка на бота для входа |
| `GET /auth/poll?nonce=` | `pending` или `ok` + токен |
| `GET /me` | список профилей с версиями |
| `GET /progress/<профиль>` | прогресс профиля |
| `PUT /progress/<профиль>` | `{data, baseVersion}` - сохранить. Если на сервере уже новее - `409` и свежие данные (ничего не затирается) |
| `DELETE /progress/<профиль>` | удалить профиль |
| `POST /auth/logout` | выйти |
| `DELETE /account` | удалить аккаунт и все данные |

Защита: запросы только с сайта и приложений (CORS), лимиты частоты, размер прогресса до 512 КБ, токены и коды в базе только в виде хэшей, сервис в песочнице systemd, наружу только через nginx с HTTPS. Тест: `node tests/test_server.js`.

## Установка (один раз)
1. **Бот.** В Telegram у @BotFather: `/newbot`, имя «Вокал под бокал», username например `vocal_pod_bokal_bot`. Сохрани токен. Нужен отдельный бот: тот, что работает для «Законных выходных», трогать нельзя - два процесса не могут читать одного бота.
2. **DNS.** В панели домена законныевыходные.рф добавь запись `A` для `api` -> IP сервера.
3. **Код на сервер:**
   ```bash
   git clone https://github.com/nchurashov/vocal.git /root/vocal
   ```
4. **Установка:**
   ```bash
   sudo bash /root/vocal/server/install.sh
   ```
   Скрипт проверит Node.js 22.13+ (если старее - подскажет команду), создаст пользователя `vocal`, сервис `vocal-api`, ночные копии базы (14 дней) и сайт nginx для поддомена с HTTPS.
5. **Токен бота:** открой `/etc/vocal-api.env`, впиши `BOT_TOKEN=` и `BOT_NAME=`, потом
   ```bash
   sudo systemctl restart vocal-api
   ```
6. **Проверка:**
   ```bash
   curl https://api.xn--80aegcchwyadfe4gvdce.xn--p1ai/health
   ```

## Обновление
```bash
cd /root/vocal && git pull && sudo bash server/install.sh
```

## Если не nginx
Направь поддомен на `127.0.0.1:8787` с HTTPS и передай заголовок `X-Real-IP`. Для Caddy:
```
api.законныевыходные.рф {
    reverse_proxy 127.0.0.1:8787 { header_up X-Real-IP {remote_host} }
}
```
